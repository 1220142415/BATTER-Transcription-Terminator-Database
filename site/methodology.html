About BTED and its data

About this database

BTED makes public bacterial transcript 3′-end datasets easier to find, compare, download, and inspect in a genome browser.

The v0.3.0 release includes 22 source datasets across 20 assemblies, with 28,399 endpoint records. See the project repository for release documentation and source material. GitHub

Assembly grouping

Datasets are grouped only when the complete reference assembly accession is identical. Grouping changes the presentation, not source identity.

Independent tracks

A track represents one processed source. Agreement between tracks is useful for comparison but is not automatically a consensus or functional proof.

Interpreting records

Observed signals, author-called endpoints and literature-curated records have different meanings. A transcript 3′-end record is not automatically a functionally proven terminator.

Files

GFF3 is the interoperable coordinate file; every endpoint is a 1-based single-base feature. The score column contains a dot, and original study-specific scores remain in attributes. Metadata records provenance, publications, accessions and limitations.
