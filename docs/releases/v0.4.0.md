# BTED v0.4.0 数据说明

本版按**参考基因组**整理文件。共有 21 个参考组装、14 篇论文、25 份来源登记和 29,460 条转录本 3′ 端位置记录。其中 `BATTER_S1_002` 只有核查信息，没有端点。原有 28,399 条记录未改动；新增的 1,061 条来自 Cascino 论文。论文与来源的对应关系见[来源说明](../SOURCES.md)。

## 文件怎么读

```text
data/public/v0.4.0/
├── genomes/<GCF 组装编号>/
│   ├── metadata.tsv
│   └── studies/PMID_<论文编号>/
│       ├── endpoints.gff3.gz
│       └── [该研究确有的基因关联或条件观察表]
├── release.json
└── SHA256SUMS.txt
```

| 文件 | 一行或一条记录代表什么 | 用途 |
|---|---|---|
| `metadata.tsv` | 该基因组的一份来源数据 | 用表格软件查看论文、实验方法、记录数、证据类别、许可、原始数据和文件路径。 |
| `endpoints.gff3.gz` | 一个有来源编号的 3′ 端位置 | 用 JBrowse 或其他基因组软件查看；坐标从 1 开始，起点与终点相同。同一论文的不同来源保留各自编号。 |
| `gene_associations.tsv.gz` | 论文补充表中一个基因与 3′ 端的对应记录 | 共 805 条，其中 345 条找不到对应的公开端点，仍保留自身坐标；这些记录不增加端点总数。 |
| `condition_observations.tsv.gz` | 一种实验条件下对端点的一条观察 | 共 2,277 条；同一端点可能有多条观察，也不增加端点总数。 |

后两种附表只出现在确有该数据的研究目录。`release.json` 是供程序核对文件名、记录数和校验值的清单；网页不把 JSON 当作阅读或下载入口。`SHA256SUMS.txt` 可校验公开文件的原始字节。

## 新增研究的取舍

Cascino 论文的补充表中，1,061 条写为 `defined end`。我们逐行对照原始 Table S1 的工作表行号，核对了类别、链、位置和原始分数；三个来源分别有 388、331、342 条。原工作簿的 SHA-256 为 `2fd20543f7b68c791b194628f5801133a6ff185e397bc7909952a76315ee5be7`，论文全文登记为 CC BY 4.0。另有 196 条写为分散峰或不确定的记录，本版没有公开。Fuchs 的再发布许可尚不明确，TERMITe 的位置由软件从实验数据计算；这两批材料也没有混入本版端点。

论文使用 `CP000100.1`，浏览器参考序列为 `NC_007604.1`。两条序列均为 2,695,903 bp，逐碱基相同，SHA-256 为 `5fb438ec6391898e01a7774c114b37d7852c64cd115de2c1628cefecb6d5f4a6`。下载的研究 GFF3 保留论文序列名；仅浏览器轨道使用已核对的 RefSeq 名称。三个来源在浏览器中仍是独立轨道。

## 信号轨道与旧版

`BATTER_S1_001`、`S1_003`、`S1_004`、`S1_005` 各有正链和负链 BigWig 实验信号，浏览器默认显示。它们是测序信号，不等于已确认的端点；其他来源目前没有本站可用的信号轨道。本版没有新增 BAM 或重新处理原始 reads。

v0.2.0 和 v0.3.0 的逐文件原字节及路径保存在 [`data/archive/`](../../data/archive/) 的校验归档中。旧版已上传的参考资产和 8 个 BigWig 继续引用固定提交 `90651318aedf5a5ca26b8308070927d36fd3d6c9`；新版 74 个文件位于 [Hugging Face v0.4.0 固定提交](https://huggingface.co/datasets/liurulong/terminator/tree/eea5b7225975b224a1c837f60c4fa10497fef022/v0.4.0)，不复制这些旧版大文件。

在仓库根目录运行 `python scripts/validate_bted_v0_4.py`，可同时核对新发布文件、旧版归档及记录数。校验通过说明格式、关联和原值符合本版规则，不表示重新证明了每个位点的生物学功能。
