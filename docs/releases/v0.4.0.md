# Experimental data release v0.4.0

The frozen release contains **21 registered reference assemblies, 14 publications, 25 source registrations and 29,460 RNA 3′-end records**. S002 is metadata-only, so the current experimental collection has 20 members. The release retains 28,399 earlier records and adds 1,061 from the Cascino study. See the [source catalogue](../SOURCES.md).

## Files

```text
data/public/v0.4.0/
├── genomes/<assembly-accession>/
│   ├── metadata.tsv
│   └── studies/PMID_<pmid>/
│       ├── endpoints.gff3.gz
│       └── supplementary tables, where available
├── release.json
└── SHA256SUMS.txt
```

| File | Record unit |
|---|---|
| `metadata.tsv` | One source dataset for the reference; publication, assay, counts, evidence and accessions |
| `endpoints.gff3.gz` | One source-identified 3′ end; 1-based inclusive coordinates with equal start and end |
| `gene_associations.tsv.gz` | One author-reported gene–endpoint association; 805 rows, of which 345 lack a matching published endpoint and retain their own coordinates |
| `condition_observations.tsv.gz` | One condition-specific observation; 2,277 rows, with multiple observations possible for one endpoint |

Supplementary rows do not increase the endpoint total. `release.json` and `SHA256SUMS.txt` record the file inventory and integrity values. Frozen metadata describes this release; production ZIP metadata is generated from corrected D1 fields.

## Added study

The Cascino Table S1 includes 1,061 records labeled `defined end` across three sources (388, 331 and 342). Another 196 dispersed or uncertain records remain outside the published endpoint set. Worksheet rows, category, strand, position and score were checked against the source workbook. Fuchs and TERMITe candidates remain under review.

The author's `CP000100.1` and browser reference `NC_007604.1` are identical 2,695,903-bp sequences. Downloads retain the author sequence name; browser tracks use the verified RefSeq alias. The three sources remain separate tracks.

## Signals and current website

The original release reuses eight strand-specific BigWig files for S001, S003, S004 and S005 from HF revision `90651318aedf5a5ca26b8308070927d36fd3d6c9`. Later website updates also register two condition-specific signals for S021. Current availability and conditions come from D1; this frozen package is not a complete inventory of the live site's tracks.

BigWig display uses visible-window scaling without changing file values. Published experimental endpoints, model predictions and augmentation regions have separate counts. See [browser controls](../browser-controls.md).

The 74-file v0.4.0 package is at [HF revision eea5b7225975b224a1c837f60c4fa10497fef022](https://huggingface.co/datasets/liurulong/terminator/tree/eea5b7225975b224a1c837f60c4fa10497fef022/v0.4.0). Earlier release bytes remain in [`data/archive/`](../../data/archive/).
