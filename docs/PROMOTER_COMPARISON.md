# BTED 与 promoter 网站的功能对比

对比日期：2026-10-03。按用户要求排除预测功能、模型分数和相关登录／任务系统。参考项目为 RAPPTOR 当前本地源码；不是对其线上全部数据的重新审核。BTED 当前科学数据版本为 v0.4.0，21 个参考组装、24 个公开来源和 29,460 条端点，另有 1 个仅供核查的来源。

| 功能 | Promoter / RAPPTOR | BTED 现状 | 最简处理 |
| --- | --- | --- | --- |
| 首页与目录 | 独立首页、统计和基因组目录 | 已有独立首页、统计、BATTER 正式论文和代码引用 | 已补齐 |
| 统一基因组入口 | 在同一浏览器组合实验 TSS 和参考注释 | 实验端点、参考注释和已有信号在同一个基因组页 | 已有，无须另建多套页面 |
| 多关键词搜索 | 多词同时匹配，结合来源与分类筛选 | 本次补齐多词搜索，可跨物种名、组装号和同一来源的信息匹配 | 复用当前 DOM 中的检索文字，无搜索服务 |
| 分类、来源筛选及排序 | 分类层级、数据类型、注释状态，支持排序 | 搜索和数据类型；单独的门→纲→目→科→属联动分类栏，支持排序 | 移除论文、方法、证据及信号筛选；信息留在表格和详情，分类仅使用已有元数据 |

| 浏览器加载与失败提示 | 文件状态、错误提示、可重试 | 本次增加加载提示、超时提示和 Reload；分享恢复失败可回到默认视图 | 使用已有 iframe bridge，无新状态库；逐轨道失败检测仍待补 |
| 位置、缩放和轨道分享 | 共享链接恢复位置及轨道布局 | 已有共享链接及剪贴板失败时的手工复制 | 已有 |
| 轨道颜色、链向信号 | 链向注释、正负分数镜像 | 正负链颜色、实验 BigWig 镜像及轨道说明 | 已有，不把实验信号改名为模型分数 |

| 点击基因后的详情 | 页面内的详情侧栏；已有保持 SimpleFeature identity 稳定的序列组件补丁 | 使用 JBrowse 原生详情，尚未单独验证同一序列组件补丁 | 当前索引 Failed to fetch 与该渲染补丁不同；需另测详情和序列显示 |

## 本次补齐

首页现已与基因组目录分离：`index.html` 展示发布统计和正式 BATTER 论文／官方代码仓库引用，`genomes.html` 负责搜索与筛选。Home、Genomes、Data notes、Usage 四个导航分别高亮对应页面。

1. 顶部 Usage 导航及当前页标识，保留页脚入口。
2. 多关键词组合搜索；数据类型按基因组已有轨道筛选。分类栏必须从门逐级选择，下级在全部上级选定后解锁；更换上级时清空下级，共享链接恢复完整分类路径。
3. 浏览器加载、超时和重试提示；重试更新 iframe bridge nonce，忽略旧页面回复。
4. 来源说明使用原生 `<details>`，显示已存在的文章许可、再发布状态、发布状态和限制。

## 本次基因组报错

`GCF_000005845.1` 对应 `NC_000913.2`，参考索引存在且内容为 `NC_000913.2\t4639675\t72\t70\t71`。带线上站点 Origin 的直连索引响应为 200，FASTA 局部读取为 206，CORS 允许该 Origin；实验端点文件也正常。浏览器复现报错为 `Failed to fetch ... reference.fna.fai`，只说明该浏览器的数据请求失败，不能据此断定文件缺失或基因组版本错误。JBrowse 自带的 CORS 缓存重试以及 promoter 的请求选项在复现环境中均未恢复直连，所以具体的网络／缓存原因仍不能完全区分。

加载补丁保留固定版本 Hugging Face 直连和原有 Range。仅捕获未被用户取消的网络异常，然后按发布清单重试同一文件的既有 D1 代理；要求 URL／版本和返回的 SHA-256 元数据一致，避免混用版本。代理成功后，该文件在当前 JBrowse 上下文继续使用代理。不存在的文件、取消请求和未登记的版本不转换成另一份数据。

序列默认显示两行 DNA 碱基和六个翻译阅读框。JBrowse 4.3.0 原生渲染器的字母显示阈值由 12 px/bp 调为 6 px/bp，DNA 字体随宽度缩小；更远的缩放仍使用原生色块。补丁在构建时核对固定程序的 SHA-256，保留原生坐标和翻译算法，并使用新的资源文件名避免旧缓存。

所有改动复用现有 Python 构建、原生 JavaScript、JBrowse、D1 和 HTML。未增加 npm 依赖、前端框架、搜索服务或用户认证。数据源与加载逻辑继续分离；浏览器修复不改变科学数据记录，也不更新 Hugging Face。
